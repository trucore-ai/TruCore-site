# First User Quotes

> Capture exact wording from real user interactions. No paraphrasing, no fabrication.
> Every entry must be traceable to a real conversation.

---

## How to Log a Quote

1. Copy the exact words the user said or typed.
2. Note the source (DM, Discord, tweet reply, call, etc.).
3. Record the date and the user's handle (or "anonymous" if no permission).
4. Tag the quote type so it can be filtered later.

---

## Quote Types

| Type | Description |
|------|-------------|
| positive | User expressed satisfaction, clarity, or excitement |
| confusion | User was unclear on something, useful for improving UX |
| insight | User surfaced a use case or angle you hadn't considered |
| objection | User pushed back or expressed skepticism |
| integration | User mentioned building with ATF or connecting it to their system |

## Ready-to-Use Formats

Once you have real quotes, convert them into these formats:

### Tweet Snippet

```
"[exact quote]"
  — [handle], [role/category]
```

### README / Landing Page

```
> [exact quote]
> — [handle or "early user"]
```

### Pitch Deck Slide

```
[exact quote]
[handle] · [category] · [date]
```

---

## Rules

- **Never paraphrase.** Use the user's exact words.
- **Never invent quotes.** If you don't have a real one, leave the row empty.
- **Always ask permission** before using a quote publicly. Record permission status in the table.
- **Log confusion quotes too.** They are just as valuable for product improvement.
