# Proof Output

Store first external CLI run artifacts here.

## What Goes Here

- Screenshots of CLI output from real users
- Copied terminal output from real users
- Receipt verification output from real users
- "This worked" confirmation messages

## Labeling

Every file must be labeled with one of:

| Label | Meaning |
|-------|---------|
| `real` | Produced by an external user running the CLI |
| `demo` | Produced internally for demonstration purposes |
| `representative` | Realistic example, not from a live run |

## Naming Convention

```
YYYY-MM-DD_handle_action.ext
```

Examples:
- `2026-03-21_anon1_atf-trade-output.txt`
- `2026-03-21_anon1_receipt-verify.png`

## Rules

- No fabricated output
- Every artifact must be traceable to a real interaction
- Note the source platform and context
