# Force First External CLI Runs

Execution checklist. No new docs, no new systems. Just get someone to run `atf trade`.

## The Message (copy-paste this exactly)

> Quick ask, can you try one command and tell me what happens?
>
> It's safe (demo mode, no wallet, no on-chain tx):
>
> npm install -g @trucore/atf
> atf trade
>
> Takes ~5 seconds. I'm trying to see if the UX is clear.

## Target Selection Criteria

Pick 5 people who are:

- Technical (can run npm commands)
- Likely to try something quick
- Not random retail
- Active in the last 7 days

## When Someone Responds

1. Reply within 5 minutes if possible.
2. Do NOT oversell. Do NOT explain everything.
3. If they run it, ask: "What did you expect vs what happened?"
4. Copy their exact words into first_user_quotes.md.
5. Log the signal in first_usage_signals.md.
6. If they share output, save it in proof-output/ with the correct label.

## What Counts as Proof

Get at least ONE of these from at least ONE person:

- Screenshot of CLI output
- Copied terminal output
- "This worked" message
- Receipt verification output

## First Positive Signal

Watch for any of these phrases or sentiments:

- "This is useful"
- "I would use this"
- "How do I integrate this?"
- Any variation that signals real interest

Mark as FIRST POSITIVE SIGNAL in first_usage_signals.md.
